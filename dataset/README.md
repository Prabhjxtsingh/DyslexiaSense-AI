# Dataset layout

- `raw/handwriting/` contains the existing handwriting images and metadata.
- `raw/assessment_records/` contains the existing desktop and tablet assessment
  CSV files used by tabular training.
- `raw/audio/`, `processed/`, and `metadata/` are reserved for future datasets.

The proposed reading, audio, writing, and combined feature CSVs, data dictionary,
and label definitions were not present in the supplied project, so no placeholder
data files were created.
